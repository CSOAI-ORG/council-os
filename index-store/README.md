# index-store — the compounding asset.

Time-series, queryable, signed corpus across all tracked instruments. This is the
moat: attestations others cannot retroactively reproduce. Seeded from
`corpus-index.json` (the current coverage snapshot); grows one row per attestation
over time. Later becomes the paid data/index/API tier — the main site stays free
(Moody's / DeFiLlama / Chainalysis pattern).
